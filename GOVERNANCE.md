# Governance

irlpls is a small public project. Today one maintainer decides. Contact: hello@irlpls.com.

## What is decided where

- **The standard** (`docs/STANDARD.md` and `schema/`): the maintainer. A change needs a changelog entry, and a new date version if a field is removed or renamed.
- **Cards:** the provider, for its own card. Anyone may compile an `unclaimed` card from public sources, citing a source for every claim. A card becomes `provider-maintained` when the provider serves it from its own domain.
- **The benchmark:** irlpls shows what each provider states about each guarantee, and which separate verifiers have checked it. It checks nothing itself, and a card has no overall score.

## What irlpls will not do

- Capture anything, sell data, or take a cut.
- Rank providers for money, or accept payment to change a card.
- Let a compiled card outrank the provider: where a provider states something itself, its own statement wins.

## When this changes

This page is written for a project with one decision-maker. It changes when other organisations implement the standard independently. The next step then is a neutral home (a Linux Foundation project or a W3C community group) with a written process for changes, and a conformance suite anyone can run. Until then, every change is recorded in the changelog.
