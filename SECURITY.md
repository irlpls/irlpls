# Security policy

## Reporting

Email: hello@irlpls.com

Please send details privately and do not open a public issue for a
vulnerability. Include what you found, how to reproduce it, and what it affects.
We aim to acknowledge within a week. This is a volunteer project with no SLA.

## Scope

In scope:
- the `irlpls` Python package, CLI and MCP server
- the build and validation tooling in this repository
- the published site generated from this repository

Out of scope:
- the third-party providers described by cards, and their services
- findings that need a compromised local machine
- automated scanner output with no demonstrated impact

## No bounty

There is no bug bounty. We will credit reporters who want credit.

## Overclaiming cards

A card that overstates what a provider does (capabilities, coverage, price,
privacy, consent, safety or certifications) is treated as a defect and a
correction request, not a feature. Report it the same way, with a public source
if you have one. On a confirmed report we correct or downgrade the claim, or
withdraw the card, and record the change in the changelog. We do not keep a card
live while we know it overclaims.
